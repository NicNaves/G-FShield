# Escopo dos repositórios do G-FShield

Este repositório público contém o software, a configuração de implantação, os testes e a documentação operacional do G-FShield. Fontes das dissertações, apresentações de defesa, roteiros, áudios e pacotes finais do Overleaf são mantidos em um repositório acadêmico separado e privado.

Uma branch deste repositório não torna arquivos privados. Antes de publicar, conferir o destino remoto e o conteúdo do commit. Não acrescentar arquivos de ambiente, credenciais, dependências instaladas, caches, cópias de trabalho ou backups volumosos.

Os materiais e resultados que já fizeram parte de revisões públicas não são tornados privados retroativamente por essa separação. A manutenção do código não deve substituir os identificadores imutáveis citados nos protocolos experimentais.

Ausência de arquivos numa cópia local não comprova que sua remoção foi intencional. Confirmar a comparação com a revisão publicada antes de enviar exclusões em massa, especialmente do frontend.
